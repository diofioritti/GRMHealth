Aviso importante

Esta aplicação é uma prova de conceito. As respostas são geradas por IA e podem conter erros. Não substitui avaliação e conduta de um profissional de saúde.

Problemas comuns
1) Status mostra “Falha”
Verifique se a API está rodando. Se estiver usando Live Server/arquivo local, configure window.API_BASE_URL na página Config.
2) Erro 503 “Modelo indisponível”
O modelo pode ter falhado ao carregar (memória insuficiente, falta de token, etc). Verifique logs do servidor e ajuste DEVICE/USE_QUANTIZATION no .env.
3) Primeira resposta demora muito
Isso é esperado por causa do lazy-loading. Use a página Admin para fazer warm-up.
Checklist de configuração
  • Crie .env a partir de env.example
  • Defina HF_TOKEN se necessário
  • Use DEVICE=cpu para rodar sem GPU
  • Se tiver GPU, teste DEVICE=cuda e (opcional) USE_QUANTIZATION=true
