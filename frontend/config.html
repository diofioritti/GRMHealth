Como configurar

Esta UI não edita o servidor diretamente. Para alterar configurações, edite o arquivo .env (criado a partir de env.example) e reinicie a API.

  • MODEL_ID: modelo HF (default: google/medgemma-4b-it)
  • HF_TOKEN: token HF se necessário
  • DEVICE: auto|cpu|cuda
  • USE_QUANTIZATION: true|false (4-bit em GPU)
  • MAX_NEW_TOKENS, TEMPERATURE, TOP_P
